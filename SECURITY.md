# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**, or go to <https://github.com/ClassicMiniDIY/WireViz/security/advisories/new>.

Please include:

- a description of the issue and its impact
- steps to reproduce it
- the version or commit you tested
- a suggested fix, if you have one

You will get a reply within 7 days. Please give us a reasonable time to release a fix before you disclose the issue.

## Supported versions

Only the latest release (or the default branch, for repositories without releases) receives security fixes.
